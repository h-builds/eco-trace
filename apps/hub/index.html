React 19 Vue 3.5 Vapor Cloudflare Workers Cloudflare D1 Go/Wasm Ed25519
Why are Admin and Consumer separate apps? The Admin app is a governed, authenticated environment designed for enterprise auditors. The Consumer app is a lightweight application built for public verification. Both run natively on Cloudflare Workers, sharing the exact same cryptographic trust engine via Go/Wasm and data persistence via Cloudflare D1.
